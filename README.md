# Hemanshi Valechha Portfolio

Open `index.html` in a browser to view the portfolio. The previous `hemanshi_portfolio.html` address redirects to it. The Download Resume buttons link to the included one-page PDF at `resume/hemanshi_valechha_resume.pdf`.

To rebuild the PDF after editing `resume/build_resume_pdf.py`:

```bash
python3 -m pip install -r resume/requirements.txt
python3 resume/build_resume_pdf.py
```

The Poppins fonts used by the PDF are included in `resume/fonts/` under the SIL Open Font License.
